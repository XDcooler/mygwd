# mygwd 发布说明

mygwd 基于 [jacyl4/de_GWD](https://github.com/jacyl4/de_GWD)，继承
[XDcooler/de_GWD 的修复版本 667a39b](https://github.com/XDcooler/de_GWD/commit/667a39b3cdd069e4fad23e596540544875d8184d)。
原有作者、第三方组件及 EPL-2.0 许可证保留。

## 2026-10-25：两端 BBR 与 XanMod 菜单

- 客户端与服务端菜单 2 统一为启用当前 Debian 内核 BBR；清理重复的旧 BBRplus 入口。
- 两端菜单 3 共用官方 XanMod LTS 安装器，安装内核和头文件，为新内核配置 BBR + fq，核对启动文件与 GRUB 默认项后自动请求重启。
- 安装器限制 Debian 13 amd64、标准 GRUB 实体机或虚拟机，校验官方软件源密钥完整指纹；拒绝容器、不支持的架构和无法确认的安全启动环境。
- 保留旧内核和配置备份；下载、包状态、BBR 能力、模块、initramfs 或启动项校验失败时停止重启并尝试恢复配置。已安装包不会自动卸载。
- 保留服务端 `--kernel-check`、`--update-kernel` 与 `--enable-bbr`。Debian 官方内核命令仍需手动重启，普通应用更新不执行菜单 3。

详细流程和两端验收见 [XanMod 内核、BBR 与重启](client-xanmod.md)。菜单 3 的实际启动及网卡/DKMS 兼容性尚未在生产设备验证；本次发布不在设备上安装内核或重启。

本地回归覆盖两端菜单、共享安装器、更新来源及客户端/服务端更新流程；APT、GRUB、BBR 应用与重启均使用临时文件和命令适配器。原生 Linux 服务配置与 Debian 内核检查继续由既有 GitHub 工作流执行。

## 2026-10-25：节点切换、DoH 与更新来源修复

- 默认节点切换在真实 Xray 校验通过后同步默认出口与跟随出口，重启并等待监听；普通失败恢复原配置和代理运行状态。页面等待成功后刷新实际选择，不再提前标记成功。
- 旧服务分流引用只在连接参数完整且唯一匹配时恢复，保存节点时阻止直接删除仍被分流引用的节点。详见 [节点切换说明](node-switching.md)。
- 保存 DoH、恢复备份时迁移已知旧库更新元数据，解决 `Only the official client update command is supported` 误挡设置的问题。同 IP 更改 DoH 端口或域名也会重载 SmartDNS，重启失败会报告错误。
- 两端遗留的旧库资源环境变量在下载前迁移为 mygwd。完整客户端更新主动写入官方面板更新入口；命令行固定资源版本与面板后续更新来源独立。详见 [更新指南](update-guide.md)。
- 同步客户端安装 ZIP，并新增更新来源与安装包一致性自动检查。

节点切换与 DoH 修复已在 Debian 13 客户端部署验证：从真实局域网设备完成两个节点来回切换，实际出口随节点变化；认证面板的 DoH 更改与重新添加均返回 HTTP 200，UDP/TCP DNS 正常。更新来源清理通过临时目录中的两端下载与配置迁移测试，未据此在实机重跑完整安装或更新。

本地 Python 回归共 74 项通过，6 项因 macOS 平台条件跳过；节点切换页面逻辑检查通过。Linux 原生用例和来源检查将由对应 GitHub 工作流继续执行，不能将本地跳过视为通过。

## 已包含的修复

- Debian 13、PHP 8.4 与校验过的官方 Pi-hole 6 安装资源。
- 客户端更新通过独立后台任务运行，持久记录状态，防止并发更新。
- 更新失败恢复 cron、系统解析器和正式 DNS 端口；成功前实际验证 UDP/TCP DNS。
- 部署面板后刷新 PHP 时间戳并重启 FPM，清除旧认证代码的 OPcache。
- Pi-hole 使用正式端口 53，V2DNS 使用 5350，避免更新后遗留引导端口。
- 在 sysctl.d 持久开启 IPv4 转发，代理服务启动时再次启用；DNS 访问开关不再关闭全局转发。
- 保留节点与管理密码，按服务身份设置配置文件读取权限。

## 仓库与安装入口

client、server 的资源下载，以及面板的官方更新入口统一指向 `XDcooler/mygwd` 的 `main` 分支。
客户端安装 ZIP 与源码同步生成。IP、域名及广告规则继续使用已声明的上游数据来源。
系统内既有目录、服务名和配置格式保持兼容，完整安装步骤见 [客户端部署指南](client-deployment.md)。
