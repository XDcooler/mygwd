## 部署与兼容边界

- 这是完整客户端安装资产的修改，已同步重建 `resource/client/Archive.zip`，不能只拷贝 PHP 文件：需配套安装 root helper、sudoers、Nginx 配置、systemd 单元、配置权限及限速目录。
- 既有六项分流/UDP 权限保留，额外授权一个内部动作受限、无 CLI 参数的 broker；不使用 `sudo /opt/de_GWD/ui-*` 通配授权。是否实际应用到现有机器，需要后续部署。
- 控制台依赖 ttyd 的 Unix socket 支持和 Nginx 的 auth_request。相关机制参见 [ttyd 1.6.3 官方源码](https://github.com/tsl0922/ttyd/blob/1.6.3/src/server.c)；不支持时启动报错并停止服务，不回退到公开 TCP 控制台。
- 更新控制台中的安装脚本仍由管理员交互操作。命令退出、断开连接或 systemd 停止应结束同组进程；本轮未实测其行为。
- 失败会恢复主配置文件，但不能据此宣称已经撤销所有防火墙、系统服务或应用目录的外部变化；错误响应明确提示可能存在部分变更。
- 恢复接口接受配置备份最多 1 MiB、Bitwarden ZIP 最多 32 MiB，解压总量最多 512 MiB；NFS 挂载点限制在 `/mnt/` 或 `/media/`。更大备份及不兼容的旧参数需要管理员在 SSH 中处理。
- 定时规则刷新仍保留原机制；broker 的互斥锁用于面板管理动作，不能将其当作所有历史 cron helper 与新分流更新的一次整体事务。
