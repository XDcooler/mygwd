规则数量是测试当时的数据，后续上游刷新会变化。每天北京时间 04:00 自动刷新，网页可手动触发；项目版本轮询与自动代码覆盖已移除。桌面与手机分流界面以虚构节点 fixture 验证，390px 宽度无横向溢出。

NAS 系统升级后发现遗留 APT 安全源路径错误，现已使用官方 `trixie-security` 并移除旧 PHP 外部源。追查服务日志与升级入口后确认，旧流程先清理核心目录、主动停止 SmartDNS/V2DNS/Xray/透明代理，再尝试下载；下载失败会中止流程，使这些服务保持停止，不能仅将下载受阻归因于外部网络。旧 PHP 7.4 曾因可执行文件缺失而以 203/EXEC 失败，影响面板，现由 PHP 8.4 替代。当前旧 PHP 7.4 禁用是正常迁移结果；透明代理采用 Type=oneshot，active(exited) 也是正常运行状态，不能据此判定未启动。

已将核心包、代理脚本和规则的准备校验前移，下载准备失败时不清理核心、不停止网关或 cron、不改 DNS；重建透明代理时复用已缓存脚本。随包路由快照仍校验 SHA-256 与 CIDR，网关恢复后完成最新在线规则刷新。下载继续保留 TLS 校验、提交固定、内容校验与失败恢复。

另查到旧 `tcpTime` 的 HTTP 校时请求只有 DNS 超时，会长时间阻塞规则刷新与 DNS 收尾；现改为最多 5 秒读取 Debian NTP 同步状态，不进行 HTTP 请求或改写时钟。NAS 实测系统 NTP 已同步，新增回归覆盖同步、未同步与查询失败三种状态，均不会触发 HTTP、设置时钟或阻塞升级。

新增原生回归覆盖下载失败、损坏 ZIP、缺失核心成员、代理脚本下载失败和规则失败五种情况；21 项受影响回归全部通过。NAS 生产环境未执行故障注入；保持七服务与 cron 的 PID/启动时间不变，连续三次路由文件、一次 2.64 MB 安装包、一次 11.23 MB GeoSite 下载与散列核验通过，GeoSite 实测约 1.31 秒。路由散列按规则库的规范化 CIDR 格式比较，其余文件校验原始字节。

## 明确保留的限制

NAS 真实网络套件原始结果为 **21 通过、2 失败**，与升级前基线相同；两项均依赖直连 `1.1.1.1:53` UDP 无响应。独立使用原有绕过标记复核：直连 `8.8.8.8` 与 `223.5.5.5` UDP DNS 有效，`1.1.1.1` 超时；经过真实节点的 UDP 正常。保留原始失败，不计作通过。

隔离客户端的宿主上游本身经过同一代理，直连与代理可能得到相同出口；该校准项标为环境限制。中国及私网直连通过独立网络 fixture 检查。

未用付费流媒体账号验证地区解锁，未用实物游戏主机验证 NAT 类型、商店购买或联机；不能由规则命中替代这些结论。IPv6 透明代理、可选 Docker/Jellyfin/FileRun 等应用未作端到端验证。既有机器原有的额外面板提权规则不属于本次新增的六项固定授权，须与新安装权限区分。

服务端的无 Web 模式补充了可缺省日志的轮转处理，隔离与生产 logrotate 均通过；虚拟 EFI 分区仅跳过不支持的 TRIM，根分区维护保留，最终服务端与 NAS 无失败系统单元。

公开仓库只发布源码、安装资产和汇总记录；备份、节点凭据、证书私钥及原始私有部署日志保留在部署工作区。
